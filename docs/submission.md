# Challenge submission checklist

This file is preparation, not a published entry. No external post, session, or submission has been created.

Use the supplied Side Hustle template and `devchallenge` / `hf26challenge` tags. Published deadline: 18 October 2026, 11:59 pm PDT = 19 October 2026, 5:59 pm Melbourne AEDT. Confirm the [official challenge page](https://dev.to/challenges/hacktoberfest-week2-2026-10-12) before submitting.

- **What I Built:** explain the Australian used-laptop reseller, repetitive screening problem, narrow T14 scope, and willingness-to-pay hypothesis.
- **Demo:** record live extraction and evidence review; show an accessory rejection and unknown-field review. Label synthetic data prominently. Do not present simulated margins as observed profits.
- **Code:** link this repo, reproducible setup, exact tested model, test/evaluation commands, and data provenance.
- **How I Built It:** explain local extraction, evidence validation, separate synthetic/real storage, exact-comparison baseline, explicit costs, and the no-sales-data fallback.
- **Why Does Open Innovation Matter?:** show model/prompt control, local imports/inference, no per-token inference provider bill, and honest search/hardware/privacy boundaries. Do not imply the model beat the keyword baseline in the recorded test.
- **My First User:** include only after an actual user session. Payment and realized profit remain unvalidated.
- **My Agent Session:** optional. Review transcript/private data before choosing to share.
- **Prize Categories:** Gemma is genuinely used. SerpApi discovery has a verified live integration. Do not claim deferred TabPFN/Tiger Data/Temporal/hosting integrations. Participants can enter applicable categories but can win only once.

Writing quality is weighted most heavily. A clear account of measured behaviour and known limits is stronger than unsupported accuracy, privacy, or business claims.
